# Мерцалова топь

Исходники TikTok-сериала: мило-жуткая документалка о существах ночного болота.

- `SERIES_BIBLE.md` — мир, стиль, правила, серии, очередь, как собирать.
- `PROJECT_INSTRUCTIONS.md` — текст для проекта Claude.
- `engine/` — движок навыка animation-studio (общий для всех серий).
- `ep1-obmanka/`, `ep2-tumannik/`, `ep3-podrazhatel/` — партитура, звук, картинка и озвучка каждой серии.
- `arg-pixel-test.py` — пробный пиксель-арт для будущего ARG-слоя.
