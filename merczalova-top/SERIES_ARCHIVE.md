## Как собрать серию (технически)
1. Скопировать `engine/` в папку серии: `cp -r engine epN-name/` (в репозитории движок лежит один раз).
2. Новая серия: `node <skill-dir>/scripts/new-project.js epN-name --format 9:16`, затем взять за основу `score.js`/`song.js`/`film.js` ближайшей серии.
3. `node song.js` → `node engine/render.js stills …` (проверить кадры) → `node engine/render.js video` (≈4 мин, в фоне) → `mux` → `verify` → `check`.
4. Итоговый файл - `out/<папка>.mp4`, отправить автору.
5. Заметки из практики:
   - Чтобы голос звучал в тишине, глушить (gate) отдельные дорожки музыки, а не весь микс (эп.9).
   - Счёт и короткие слова можно резать по одному и ставить каждое на свою ноту (эп.9, `c1-c5`, `gain` в `vo`).
   - Резать mp3 так: `ffmpeg -ss START -t LEN -i vo.mp3 -af "asetpts=PTS-STARTPTS,adelay=100:all=1,afade=t=out:st=LEN+0.04:d=0.06"` (с `-ss` после `-i` afade глушит всё).
   - Оборвать фразу на полуслове - по огибающей RMS (окна 20 мс), резать в провале между слогами (как в эп.6, `cutAt`).
   - Плавные переходы (затемнения, наезды) не помечать `sync` - `verify` выдаёт «?». Синхрон только на ударах, вспышках, срезах.
   - Финальный экран каждой серии: титр на 0.42H, журнал `REC 03:1N` пиксельным шрифтом (на 1 минуту больше, чем в прошлой серии) + своя деталь в темноте.
   - Таблица для копирования (артефакт `2f265911-f696-4640-8560-f9763152a113`) - исходник лежит в репозитории: `merczalova-top/publishing-table.html` (массив `DATA`); правится и публикуется заново через publish_files с этим slug.
   - Для пуша в GitHub в новом чате нужен доступ к репозиторию на запись (`add_repo` с push).
   - С 11-й события удобно задавать в секундах под реальные фразы и прижимать к восьмой: `Q(t)` в `score.js` (эп.11-12). Ноты укусов/прорастаний тогда остаются в сетке шкатулки.
   - Резать mp3 скриптом: длины считать через `python3` (у `bc` выходит «.81» без нуля - ffmpeg такое не принимает).
   - Важное (раскрытие, силуэт) держать выше 0.78H - ниже его закрывает подпись TikTok (эп.11: общий план поднят камерой).
   - Субтитры можно поднять до 0.15H, если в 0.24H стоит главный объект (эп.12, луна).
   - Звуковые «удары» без яркой вспышки в кадре помечать `sync: 'a'`, иначе `verify` даёт «?» (эп.10, мелкий всплеск).
   - В окружении удалять файлы через `rm` с глобом нельзя (блокируется) - старые кадры просто перезаписываются при новом `stills`.

## Бестиарий - подробно
- Карточки № 01-13 - страницы журнала наблюдателя (`bestiary/`): данные `cards.js`, подписи к постам `captions.js`, вёрстка `film.js`, кадры существ `img/`, готовые картинки `cards/NN_id.jpg`. Рендер: `cp -r ../engine .` → `node render-all.js [id…]` (PNG в `out/cards/`, потом в jpg). Таблица: `node build-table.js` → `bestiary-table.html`, артефакт `f569e9ff-5850-4d72-99ff-88ebd357a292` (claude.ai/artifact/XJg87SycNaE2EuQh5shi2u), публикуется publish_files: `index.html` + `cards/*.jpg`.
- **Кто пишет:** машинопись - старый нежный справочник наблюдателя; ручка - его поздние пометки (зачёркивает милое слово → «?», обводит деталь, красная пометка). Канал ведёт «рассказчик» (Обманка) и выкладывает страницы как милый бестиарий - пометки проскакивают мимо него, как Морзе в окне.
- **Все страницы - настоящие записи наблюдателя** (решение автора 08.11.2026; подделок в бестиарии нет). REC на распечатке - снимки с разных ночей, все до 03:11. Пометки к концу тревожнее: «засекай» → «не моргай» → … → «он уже здесь» (09) → «зови!» → «не ложись» → «не смотри на свет». № 12 - последняя страница (03:10:58, за минуту до «Наблюдения №4»).
- Морзе на полях 10-12 - **настоящие слова** наблюдателя, которые подделка в окне будки потом исказила: ЭТО НЕ Я (в серии ЛОЖЬ), УХОДИ (в серии ОСТАНЬСЯ), ГАСИ СВЕТ (в серии ИДИ НА СВЕТ). Лист 11 порос мхом (журнал лежал в болоте), под мхом «не засы…»; у 12 откушен угол, Морзе обрывается на «ГАСИ СВ».
- **Правило автора: после каждого готового эпизода дополняем бестиарий** - карточка нового существа в `cards.js` (+ кадр в `img/`), подпись в `captions.js`, рендер, `build-table.js`, перепубликация таблицы-артефакта.
- Для существ 13+: страница тоже настоящая, но REC должен быть до 03:11, а № 12 остаётся последней по времени - значит, новым карточкам давать время с более ранних ночей. Флаг `forged` в `film.js` (ровный почерк подделки) оставлен на будущее, не используется. Порядок постов в канале: 03 вышла, дальше 01, 02, 04…12.
