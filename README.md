# checker — сводки по одной беседе Telegram в Claude

Сервер даёт Claude прочитать одну вашу беседу в Telegram. Только прочитать:
ни отправить, ни удалить, ни отметить «прочитано» он не может. Работает
бесплатно на Render и подключается к Claude как свой коннектор. Всё
настраивается с телефона.

После настройки в приложении Claude достаточно написать:

> Сделай сводку по беседе за последние 3 дня: главное, решения, вопросы ко мне.

## Что понадобится

- аккаунт GitHub (уже есть — этот репозиторий);
- аккаунт Google (для одного шага в Colab);
- 30–40 минут.

## Шаг 1. Ключи API Telegram

1. Откройте в браузере https://my.telegram.org и войдите по номеру телефона
   (код придёт в Telegram).
2. **API development tools** → заполните App title и Short name любыми словами
   латиницей, Platform — Other → **Create application**.
3. Сохраните **api_id** (цифры) и **api_hash** (длинная строка) в заметках.

## Шаг 2. Строка сессии (через Google Colab)

1. Откройте:
   https://colab.research.google.com/github/defyhengin/checker/blob/main/colab_login.ipynb
   Colab попросит доступ к GitHub, потому что репозиторий приватный, —
   разрешите.
2. Нажмите ▶ у первой ячейки (установка, ~30 секунд), затем ▶ у второй.
3. Под второй ячейкой введите api_id, api_hash, телефон, код из Telegram и,
   если включён, пароль 2FA.
4. Скопируйте выведенную длинную строку целиком — это **TG_SESSION**.
5. Меню ⋮ → **Изменить → Очистить все результаты**, закройте вкладку без
   сохранения.

В Telegram придёт уведомление о новом входе с устройства `tg-readonly-mcp`,
скорее всего из другой страны (серверы Google). Это вы, сессию не завершайте.

## Шаг 3. Сервер на Render

1. Зарегистрируйтесь на https://render.com через GitHub. Карта не нужна.
2. **New → Blueprint** → выберите репозиторий `checker` → Render прочитает
   `render.yaml` и спросит значения:
   - `TG_API_ID`, `TG_API_HASH` — из шага 1;
   - `TG_SESSION` — строка из шага 2;
   - `TG_CHAT` — точное название беседы, как в Telegram.
3. **Apply**. Сборка займёт несколько минут.
4. Когда сервис станет **Live**, скопируйте:
   - адрес сервиса вверху страницы, вида `https://checker-xxxx.onrender.com`;
   - **Environment → MCP_TOKEN** — Render сгенерировал его сам.

## Шаг 4. Коннектор в Claude

1. Откройте https://claude.ai в браузере телефона (в приложении коннекторы
   не добавляются) → **Настройки → Коннекторы → Добавить свой коннектор**.
2. Название — `Telegram`, адрес — `https://checker-xxxx.onrender.com/mcp`.
3. Токен:
   - если есть поле для заголовка или токена — `Authorization: Bearer <MCP_TOKEN>`;
   - если такого поля нет — допишите токен к адресу:
     `https://checker-xxxx.onrender.com/mcp?token=<MCP_TOKEN>`.
4. Сохраните. Теперь коннектор работает и в приложении Claude.

Проверка: попросите Claude «вызови chat_info». Он должен назвать вашу беседу.

## Как пользоваться

- «Сводка по беседе за 3 дня» / «…за неделю».
- «Что писали про заказ 1234?» — поиск по беседе.
- «Есть ли вопросы, на которые я не ответил?»

Бесплатный сервер засыпает после 15 минут без запросов. Первый запрос после
паузы ждёт около минуты; если Claude сообщил об ошибке, просто повторите.

## Безопасность

- `TG_SESSION` — полный доступ к аккаунту. Он хранится только в настройках
  Render. Не вставляйте его никуда больше, в том числе в чат с Claude.
- Код этого сервера с ней может только читать одну беседу: клиент Telegram
  блокирует все остальные запросы ещё до отправки (`readonly_client.py`,
  проверка — `check_readonly.py`).
- Без `MCP_TOKEN` сервер отвечает только «unauthorized». Если токен утёк —
  в Render: Environment → MCP_TOKEN → Generate, затем обновите коннектор.
- Чтобы всё отключить сразу: Telegram → **Настройки → Устройства** →
  завершите `tg-readonly-mcp`. Затем удалите сервис на Render.
- Сообщения в беседе пишут другие люди. Сервер помечает их как данные, а не
  инструкции, но не просите Claude выполнять то, что «попросили» в чате, без
  своей проверки.

## Если что-то не работает

| Что пишет Claude | Что сделать |
|---|---|
| Беседа «…» не найдена | Проверьте TG_CHAT: название точь-в-точь как в Telegram |
| Бесед с названием … несколько | Впишите в TG_CHAT нужный id из сообщения |
| Сессия Telegram недействительна | Повторите шаг 2 и обновите TG_SESSION |
| Не удалось подключиться к Telegram | Подождите минуту и повторите |
| unauthorized / 401 | Токен в коннекторе не совпадает с MCP_TOKEN |

Если название беседы часто меняется, попросите Claude вызвать `chat_info` и
впишите в TG_CHAT показанный id вместо названия.
