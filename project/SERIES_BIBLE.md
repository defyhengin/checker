# «Пустой холодильник» — библия сериала

Канал YouTube «Что?». Low-poly 3D-шортсы про жизнь без еды. Автор работает только с телефона, общается по-русски.
Этот файл — точка входа для новой сессии: прочитай целиком, затем `project/src/`.

## 1. Постоянные правила автора
- Формат: вертикальные шортсы 720×1280, 24 кадра/с; мягкий приятный свет. Горизонтальные — редко, как отдельные «фильмы» («Сон»).
- Без голоса и музыки. Звук: всегда гул холодильника + тихие бытовые звуки.
- Субтитры: печатная машинка, Liberation Mono, по буквам; на светлом фоне — тёмная подложка (стиль Box).
- Концовка 3,5 с: «Чтобы холодильник не пустовал:» + `donationalerts.com/r/whatwhatwhat` + QR (`project/card_da.mp4`). Никогда не Boosty.
- Описание: короткая фраза, строка «Поддержать, чтобы холодильник не пустовал: donationalerts.com/r/whatwhatwhat», хэштеги. Ссылки без https/www.
- **TikTok:** вместе с каждым готовым роликом присылать автору короткое описание для TikTok (одна фраза) и 1–2 хэштега.
- Название = заголовок + те же хэштеги, что в описании (пример: «Мамин рецепт #shorts #мама #суп #жиза #3dанимация»).
- Публикация: mp4 → `videos/` этого репо → Metricool `createScheduledPost` (blogId 7770215, timezone Europe/Moscow, YouTube, type short, category FILM_ANIMATION, madeForKids=false, media = raw.githubusercontent.com/defyhengin/checker/main/videos/…) → Metricool копирует файл → из репо удалить при следующем коммите.
- Интервал: раз в сутки, 19:00 МСК (с 2.11.2026; раньше было 5 ч). Публиковать без согласования. Лимит Metricool Free — 20 публикаций в месяц: сверх лимита в Metricool НЕ ставить и НЕ класть черновиками — когда лимит месяца исчерпан, автор выкладывает сам из приложения YouTube в том же графике (раз в сутки, 19:00); я присылаю файл + готовые название и описание. С нового месяца снова ставлю в Metricool сам. Каждый готовый ролик ТАКЖЕ отправлять автору файлом.
- Новые модели не согласовывать, показывать готовый результат. Промежуточные кадры — только если попросит.
- Рук нет (отложены на следующую серию). Предметы появляются/исчезают монтажной склейкой.
- Кот в этом мире всегда сыт; пустая тарелка — только у героя.
- Не просить и не принимать пароль от Google/YouTube.

## 2. Что работает (аналитика)
Лучше всего: «Пустой холодильник» (~1 тыс.), «Голосовое от мамы» (507), «Шкаф» (219) — простые тёплые истории, мама, холодильник. Ирония про цены — 4–7 просмотров. Крючок — в первую секунду. Тёплый поворот после серии грустных — сильнее всего.

## 3. Мир и персонажи
**Студия** (`studio.py`, 6×5,5 м, h 2,6; координаты движка: x −3..3, z 0 (вход) .. 5,5 (окно), y вверх). Вход — дверь; справа от входа ванная за серо-голубой перегородкой; вдоль левой (x=+3) стены кухня: холодильник (2.65, z1.5, у входа) → шкаф с микроволновкой → мойка → плита с медной вытяжкой и кастрюлей → шкаф с чайником. Стол на двоих (1.15, 2.55) с синим подвесным абажуром. Дальняя стена: окно с ночным городом/рассветом, рабочий стол с монитором и жёлтым креслом, красный диван, ковёр. Угол — кровать с синим покрывалом, тумбочка с красной лампой.
**Герой** — всегда за кадром (POV). **Мама** — только телефон, записки, посылки. **Рыжий кот** — зелёные светящиеся глаза, миска у стола. **«Живой» холодильник** — открывается сам ночью («Я тоже голодный»), уходит к соседям («Ушёл к соседям. Там кормят. — Х.»), возвращается прыжками («У соседей тоже пусто. Я дома.»), грустит.
**Магазин** (`bl_shop.py`): отдельное одноэтажное «ПРОДУКТЫ 24» на открытой стороне П-образного двора из пятиэтажек (смещение SHOP_OFF = (−4, −26), витрина смотрит на улицу −y); во дворе площадка (песочница, качели, горка, лавочки); натриевые фонари, лужи, голые деревья. Две витрины с подоконниками, стеклянная дверь, хлеб на полке у окна, стеллажи, касса; кассир — пожилая женщина в фиолетовой жилетке; покупатель в зелёном пальто с красной корзиной.

## 6. Техника (как запустить)
- ВСЯ работа идёт через **Blender (EEVEE)**. Ранние эпизоды (до «Сна» включительно) делались в собственном быстром движке `eng.py` (numpy-рейтрейсер) — он остался только как источник геометрии студии; новые ролики — только Blender. Cycles не использовать (слишком медленно на 2 ядрах), EEVEE без raytracing.
- `pip install bpy` (Blender 5.x как модуль; Python 3.13), PIL, numpy, ffmpeg; шрифты Inter, DejaVu, Liberation Mono.
- Студийные эпизоды: `bkit.py` (импортируется; строит студию из `studio.py`/`furniture.py`/`apt.py`/`eng.py`, полый холодильник `FRIDGE` + дверца на `hinge`, кот `Cat`, свет `light()`/`LIGHTS`, `state(groups, lights, fr=угол_дверцы, fr_warm, fr_light, door, world, exp, phone)`, `cam(pos, tgt)`, `shoot(path)`, группы видимости `grp_add`). Запуск: `EP_OUT=ep_x MODE=stills BL_ENGINE=EEVEE EV_SAMPLES=24 WORLD_STR=1.0 python3 ep_x.py x 8 720 1280` (+ `MODE=anim` для анимаций).
- Магазин (для «Кассы» см. `ep_kassa.py`: `state()`, `bag_on()`, ценники на стеллаже, лента, пачка/батон/телефон): `bl_shop.py` (`SHOP_PREVIEW=1 python3 bl_shop.py 540 960` — превью), эпизод `ep_vitrina.py` (+ `section_off(k)` — гашение света по секциям, телефон перед камерой с DOF).
- Монтаж: `edit.py` — `seg(a,b,src,z0,z1,c0,c1,seq,xf,overlay)` (стоп-кадры с наездом, последовательности 24 fps, кроссфейды, оверлеи), `Mix` (гул, стук, звон, шаги, птицы, мурчание, мяу), `subs`, `final` (склейка с `card_da.mp4`), `sheet` (контрольный лист). Примеры: `ep_pie_edit.py`, `ep_recipe_edit.py`, `ep_vit_edit.py`, `parcel_final.py`.
- Экономия: стоп-кадры рендерить один раз, движение камеры — наездами при монтаже; честная анимация только где двигается объект, циклами по 30–36 кадров. 2 ядра CPU — рендеры строго по очереди. EEVEE ~10–30 с/кадр (студия), сцена магазина ~1–2 мин/кадр.
